Engine Settings
Auto-Route Onboarding Cases
When ON, cases with no doctor/office match are automatically routed to Onboarding. When OFF, Support Ninja reviews and routes manually.
Auto-Escalate to OC C&B Level 2
When ON, cases with fuzzy matches or multiple issues are automatically escalated to Level 2. When OFF, Level 1 reviews suggestions and escalates manually.
SN Return to Queue
When ON, Support Ninja Level 1 users can return their assigned case back to the available queue instead of completing or escalating.
QC Engine
When ON, submitted cases go to Pending QC for engine validation against ABS. When OFF, cases skip QC and go straight to Verified.
Verified Retention
Controls how long Verified / PAN Assigned cases stay visible on the board. Use search to find archived cases.
OC Max Open Cases
Maximum number of cases an OC / Level 2 team member can have assigned at once. Support Ninja is always limited to 1.
Enable View As Switcher
When ON, admins see the View As person switcher in the header to view the app as any team member. When OFF, the switcher is hidden.
Deep QC — Folder & Teeth Check
Folder where completed/submitted PDFs land. Deep QC scans this folder to find cases ready for validation.
Folder where PDFs are moved after passing deep QC. Failed cases stay in the completed folder for review.
Run Deep QC Check
Validates all complete/quality_review cases against ABS — checks patient name, tooth numbers, tooth count, and per-tooth products from Case Teeth table.
